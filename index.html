От поиска до отклика — один понятный путь

Каждый шаг виден и проверяем: откуда вакансия, почему такая оценка, что попало в резюме.

  1. 1

    Поиск

    Открытые доски, Telegram-каналы, gsz.gov.by, SuperJob — по вашим ролям и близким формулировкам.

  2. 2

    Оценка

    Правила отсеивают скам и стоп-факторы, модель ставит балл. Каждое решение — с цитатой.

  3. 3

    Документы

    Резюме и письмо под вакансию в PDF — только из фактов вашего профиля.

  4. 4

    Отклик

    Отправляете вы сами. Приложение лишь записывает факт отправки.

  5. 5

    Доска

    Воронка откликов, ответы, интервью и напоминания «напомнить о себе?».

Что умеет

Свой выбор модели

Облачные агенты или локальные модели: LM Studio, Ollama, llama.cpp. Подсказки по длине ответа и контексту, чтобы модель не обрывалась.

Источники

Публичные доски вакансий, Telegram-каналы без аккаунта, gsz.gov.by, «Работа России», SuperJob через официальный API. Паузы и кэш — бережно к сайтам.

Честная оценка

Правила плюс модель. «Покрытие требований»: что подтверждено фактами, что частично, где честный пробел и каких слов ATS нет в профиле.

✓ Jira, SQL≈ английский B2 (в профиле B1)— Kubernetes

Резюме и письмо в PDF

Под конкретную вакансию, без выдуманного опыта и канцелярита. Проверка текстового слоя для ATS.

Доска и воронка

Отклики, ответы, интервью и офферы по источникам. Если ответа нет N дней — напоминание с черновиком письма.

Свайпы в Telegram

Поиск по расписанию присылает лучшие вакансии по одной: «Интересно», «Неинтересно», «Откликнуться» — документы приходят в чат.

Ваши данные остаются у вас

Профиль, вакансии, документы и история хранятся на вашем компьютере. Ключи API — в защищённом хранилище Windows.

  • Без аккаунта в нашем сервисе и без телеметрии
  • Ключи хранятся в защищённом хранилище Windows (DPAPI), в файлах их нет
  • Капчи не обходятся: любую проверку проходит человек
  • Работодателям ничего не отправляется автоматически

Использование API SuperJob

  • Только поиск вакансий через официальный API SuperJob (метод списка вакансий).
  • В пределах лимитов API: пауза между запросами, не больше нескольких страниц на запрос.
  • Контакты работодателей и персональные данные не собираются и не передаются третьим лицам.
  • Каждый пользователь работает со своим ключом приложения; ключ хранится только на его компьютере.
  • Результаты показываются пользователю со ссылкой на вакансию на superjob.ru.
